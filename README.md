# MC Launcher — APK Releases

Download the official project APK from the [Releases](https://github.com/obsifox/mclauncher/releases) page. APK files are named `mclauncher-<version>.apk`.

The complete source code and GitHub Actions workflow are in the separate [mclauncher-source](https://github.com/obsifox/mclauncher-source) repository. Source release archives are named `mclauncher-source-<version>.zip`.

Android package: `ir.obsifox.mclauncher`

MC Launcher is an unofficial project and is not affiliated with Mojang Studios or Microsoft.
